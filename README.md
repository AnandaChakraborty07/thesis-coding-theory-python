# thesis-coding-theory-python

Python implementations of weight enumerators and related computations in algebraic coding theory.

## Contents

* `Complete Weight Enumerators.py`: Computes complete weight enumerators over finite fields/rings.
* `Complete Joint Weight Enumerators.py`: Implements complete joint weight enumerations for code pairs.
* `Average Complete Joint Weight Enumerators.py`: Calculates average joint weight distributions.
* `Main Theorem.py`: Verification script testing code properties and theorem equivalence.

## Requirements

* Python 3.x
* Standard libraries (`sys`, `ast`, `itertools`, `collections`)

## Usage

Run any script directly using Python:

```bash
python "Main Theorem.py"
